# Sono — сайт для персональных AI-песен

Одноэкранный мобильный квиз: вопросы → текст песни → демо → оплата (ЮKassa + Lava).
Страница не листается — всё на одном экране, как приложение. Заточено под мобильный трафик.
Пока работает в **демо-режиме** (заглушки вместо генерации), чтобы можно было посмотреть и потыкать.

## Что внутри

```
sono-site/
├── index.html      — экран (один, без прокрутки)
├── css/style.css   — внешний вид (мобильный дизайн)
├── js/app.js       — логика квиза (в начале файла блок CONFIG — все настройки)
└── README.md       — этот файл
```

## Квиз повторяет бота один в один

Страна → повод → жанр → вокал → финальный штрих (имя + истории) → текст песни (Продолжить / Изменить) → демо 0:30 → пакет (1/2/3/10 генераций) → почта → оплата.

## Как поменять цены / тексты

Открой `js/app.js`, в самом верху блок `CONFIG`:

- `MOCK_MODE: true` — демо-режим. Когда подключим настоящий API, поменяем на `false`.
- `API_BASE` — адрес сервера, где живёт генерация.
- `PRICES` — цены и пакеты. Просто впишите свои цифры в рублях и долларах.

Тексты на странице (заголовки, FAQ, примеры) меняются прямо в `index.html`.

## Как выложить на GitHub Pages (пошагово, простым языком)

1. Зарегистрироваться на [github.com](https://github.com) (если аккаунта нет).
2. Нажать **«+» → New repository**, назвать например `sono-site`, выбрать **Public**, создать.
3. Нажать **uploading an existing file** и перетащить все файлы из папки `sono-site` (index.html, папку css, папку js), затем **Commit changes**.
4. В репозитории: **Settings → Pages**, в разделе Source выбрать ветку **main**, папку **/ (root)**, нажать **Save**.
5. Через 2–3 минуты сайт будет доступен по адресу вида:
   `https://ВАШ_ЛОГИН.github.io/sono-site/`
   Это адрес можно вставлять в рекламу и пересылать клиентам, пока не куплен домен.

Когда купите домен: **Settings → Pages → Custom domain**, вписать домен, сохранить. Готово.

## Что нужно для включения «настоящей» генерации и оплаты

1. Доступ к API бэкенда (`/docs` + секретный ключ) и разрешение запросов с сайта (CORS) — **спросить у программиста**.
2. Боевые ключи **ЮKassa** (РФ) и **Lava.top** (зарубежные карты).
3. Домен — нужен для страницы возврата после оплаты и для настроек платежей.
